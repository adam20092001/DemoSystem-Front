# Demo POS - Gestión Comercial

Demo modular basada en `Documentacion_Tecnica_POS_Gestion_Comercial_MVP.docx`.

## Estructura

- `frontend/`: Angular 20 LTS, organizado por features y rutas lazy.
- `docs/`: decisiones, contratos de integración y hoja de ruta del frontend.

## Inicio rápido

```bash
cd frontend
pnpm install
pnpm start
```

La autenticación y la administración de usuarios ya consumen el backend REST real. Los módulos de negocio restantes conservan datos de demostración hasta que sus endpoints estén disponibles.
